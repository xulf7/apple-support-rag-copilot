## 接下来怎样分工

**开发工作**：确认生成服务 → 接入一次正常生成 → 检查回答及引用 → 浏览器验收 → 再做扩库和正式评测。

**写作工作可以并行**：

1. 根据架构说明完成项目背景、服务对象、正常流程和技术选择。
2. 根据资料指南说明官方来源、清洗、切块和出处追溯。
3. 将已完成的检索结果与尚未验证的生成效果分开写。
4. 真实生成验收后补示例、回答质量结果、界面截图和演示过程。
